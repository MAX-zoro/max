# 三季 · Discord 信息台

用个人账号读取自己可见的 Discord 频道，在自己的服务器归档新消息。基于 [discord.py-self](https://github.com/dolfies/discord.py-self)（MIT）；不需要在“币风港”添加机器人。

## 使用流程

1. 启动服务，使用工具后台密码进入网页。
2. 在“连接 Discord”中输入你自己的个人账号 token。这里不是 Discord 官方 OAuth 登录，也不接收账号密码或验证码。
3. 下拉选择“币风港”，勾选频道，点击“保存并开始监听”。
4. 网页自动显示新消息，关闭网页后后台仍然工作。暂停后恢复会补查暂停期间的消息。

工具只保存选定频道的消息。没有发消息、加群、加机器人或抓取成员资料的功能。

## 本地运行（Windows）

需要 Python 3.12。使用 PowerShell 7 运行 `./start.ps1`，打开 <http://127.0.0.1:8765>。安装使用 `requirements.lock` 固定已测试的依赖版本；Linux 构建还会按平台解析这些包的依赖。

首次启动会生成 `data/admin-password.txt`，请在本机打开查看后台密码。Discord token 验证成功后保存到 `data/discord-token.txt`，不会返回网页、输出到日志或提交 Git。断开账号会清空保存的 token。

`data/` 含私密信息，不要分享或提交。Linux 下目录权限为 700、凭据文件为 600；Windows 应使用仅你可访问的文件夹。凭据文件没有额外加密，服务器管理员能读取，因此服务器本身必须可信。

## 部署到 Linux 服务器

准备 Docker Engine / Compose，以及可连接 Discord 的网络。上传项目源码，不要上传本地 `.venv`、`data`、`.env` 或测试输出。

```sh
cp .env.example .env
# 编辑 .env：PUBLIC_ORIGIN=https://dc.你的域名
# 可自行指定 ADMIN_PASSWORD（至少 12 字符），留空则生成随机密码。
docker compose up -d --build
```

默认只将端口绑定到服务器的 `127.0.0.1:8765`。使用现有 Nginx/Caddy 反向代理，并保留原始 Host 头；远程访问必须配置 HTTPS。Caddy 示例：

```caddy
dc.你的域名 {
    reverse_proxy 127.0.0.1:8765
}
```

如果未在 `.env` 指定密码，由你在服务器终端执行以下命令查看（不要把输出发到聊天）：

```sh
docker compose exec discord-reader cat /app/data/admin-password.txt
```

浏览器打开你配置的 HTTPS 地址，登录后台并填写 token。不要把个人 token 放进网址、命令参数、GitHub 或第三方 token 查询网站。

容器自动重启；数据保存在 `archive-data` 命名卷。升级前停止服务并备份整个数据卷，数据库、媒体和 token 都在里面。不要运行带 `-v` 的清理命令，否则可能丢失归档。

## 当前行为与边界

- Gateway 实时接收消息，每 60 秒按频道进度补查；SQLite 按消息 ID 去重，重启后保留进度。新选频道只采集选择时刻之后的消息。
- 正文、作者、频道、时间、回复 ID、嵌入内容、附件链接保留；已保存消息在线编辑时尝试更新。不追踪删除，也不保证断线期间的编辑同步。
- 文字频道和当前已加载的帖子/子频道可单独选择。勾选父频道不会自动包含以后创建的帖子；新帖子需要刷新后勾选。不能读取账号无权访问的频道。
- 带历史读取权限才能自动补查。断线期间已被删除、已撤销权限或已消失的内容无法恢复，不能保证任何情况下“零遗漏”。
- 下载 Discord CDN 的附件、图片、视频和贴纸。每个文件最多 100 MB；外部网站媒体不自动下载，保留原链接；失败状态会显示并重试。外链或过期 CDN 链接无法保证永久恢复。
- 所有消息、媒体和 API 都需要后台登录，默认不会公开群内容。当前网站即本工具的信息台；接入三季交易的具体页面需要确定接收接口。
- 个人账号自动化不受 Discord 官方支持，可能导致账号受限。接口变化也可能需要更新依赖。

## 验证

```powershell
.\.venv\Scripts\python.exe -m unittest discover -s tests -v
```

测试使用离线消息和模拟连接，不访问真实 Discord 账号。重点覆盖断线补查顺序、去重、暂停恢复、权限失败、持久化、分页、媒体下载与大小限制、登录/CSRF、凭据不回显和媒体访问保护。

真实验收：连接账号，选一个你可读的频道，等频道自然出现一条新消息，核对文字/图片；重启工具后检查进度与重复条目。工具不会为测试向 Discord 发送消息。
